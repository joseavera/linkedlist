mensaje del curso
// Mtro. Vera → grupo.forEach(alumno => decirles())

Este curso no fue fácil. Estructuras de datos no lo es — y tampoco debería serlo. Porque las cosas que valen no compilan a la primera.

Vieron arreglos, listas enlazadas, pilas y colas. Aprendieron que elegir la estructura correcta no es un detalle técnico — es pensamiento de diseño. Es preguntarse: ¿qué operación importa más aquí? ¿Qué tan rápido necesito acceder? ¿Va a cambiar este dato?

Esas preguntas las van a hacer por el resto de su vida profesional, aunque nunca vuelvan a escribir un Stack<T> a mano. El razonamiento que practicaron aquí — eso sí se queda.

Se hizo el mejor esfuerzo de ambos lados de esta clase. El mío para que cada slide, cada ejemplo y cada línea de código tuviera sentido para ustedes. El de ustedes para aparecer, intentarlo, equivocarse y volver a intentarlo. Eso es exactamente lo que hace un programador.

Cuídense. Sigan construyendo. Y recuerden que un buen programa —igual que una buena vida— no se escribe de una sola sentada. Se refactoriza, se mejora, y nunca se deja de iterar.

Fue un honor compartir esta clase con los 16. Cada uno de ustedes dejó algo en el historial de este curso — y eso no se puede hacer git revert.
